# Simple Sales Dashboard Design (Power BI)

## Project Overview

This project demonstrates the design and development of a **Simple Sales Dashboard** using **Microsoft Power BI**. The dashboard provides an interactive visualization of sales performance across different **months, regions, and product categories** using the **Superstore** dataset.

The objective is to transform raw sales data into meaningful business insights through effective data visualization and interactive filtering.

---

# Objective

The primary objective of this project is to:

* Import and analyze sales data.
* Visualize monthly sales trends.
* Compare sales across different regions.
* Analyze sales distribution by product category.
* Create an interactive dashboard using slicers.
* Present key business insights for decision-making.

# Dashboard Features

The dashboard includes the following visualizations:

### Monthly Sales Trend (Line Chart)

* Displays sales performance across different months.
* Helps identify seasonal sales patterns.

### Sales by Region (Bar Chart)

* Compares sales across all regions.
* Highlights the best-performing and lowest-performing regions.

### Sales by Category (Donut Chart)

* Shows the contribution of each product category.
* Makes category-wise comparison easier.

### Total Sales Card

* Displays the overall sales value.
* Provides a quick business performance summary.

### Interactive Slicers

* Region
* Category

These slicers allow users to dynamically filter the dashboard.

---

# Dashboard Insights

### 1. Monthly Sales Trend

Sales fluctuate across different months, indicating seasonal variations in customer demand and purchasing behavior.

### 2. Regional Sales Performance

The West region recorded the highest sales, while the South region generated the lowest sales, highlighting differences in regional business performance.

### 3. Category-wise Sales

Technology emerged as the best-performing category, contributing the largest share of total sales compared to Furniture and Office Supplies.

### 4. Interactive Analysis

The Region and Category slicers enable users to filter data dynamically, making the dashboard more interactive and improving sales analysis.

### 5. Overall Performance

The dashboard provides a comprehensive overview of total sales, regional performance, category-wise distribution, and monthly sales trends to support business decision-making.
